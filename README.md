# Free certificate course claims, 2026

A small static page that carries the dataset summary, the citation and the DOI for an audit of
fifteen courses advertised as free-with-certificate.

- **Data (CSV):** https://rapidvibe.pages.dev/data/free-certificate-courses.csv
- **Data (JSON):** https://rapidvibe.pages.dev/data/free-certificate-courses.json
- **Readable version:** https://rapidvibe.pages.dev/posts/free-certificate-courses-dataset
- **DOI:** https://doi.org/10.5281/zenodo.23531829 (CC BY 4.0)

The page is a citation aid, not a copy of the article: the canonical version of the dataset page
lives on rapidvibe.pages.dev, and this page points search engines there with a `rel=canonical`.
